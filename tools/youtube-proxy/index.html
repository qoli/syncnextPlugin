在正式版 Syncnext 開始測試

  1. 設定 → 插件開發者 → 開啟「顯示插件開發入口」。
  2. 回主畫面進入「插件開發」，貼上此網址：
  3. 選「重新載入」，再開啟「正常模式」預覽。
  4. 預設「繁中 · AVC 原畫質」顯示繁中分組，選播放列表後選分集。其他語言可在「全部播放列表 · AVC」選取。Premium 畫質請進入「Premium 1080p AV1」頁；沒有提供該畫質的影片會明確失敗。

Mac 需持續執行並與 Apple TV 互通。Cookie 保留在 Mac。AVC 使用 HLS WebVTT；Premium 使用原始 AV1 MPD 與外掛 VTT，需要 App 支援插件 subtitle 欄位。未提供繁中字幕時，狀態會顯示「無繁中字幕」。

目錄於代理啟動時取得，分集首次開啟時取得；重新啟動代理可更新目錄。Cookie 失效會自動從 Arc CDP 更新。每次選播都重新解析串流。搜尋範圍是本站播放列表名稱與 SEED 驗證樣本；語言分組不保證所在地可播放。
